# Mother's Day

A simple and elegant static webpage dedicated to celebrating Mother's Day.  
Built entirely with HTML, this project is perfect for showcasing messages, poems, stories, or tributes to mothers around the world.

## Features

- 100% HTML — no dependencies or backend required
- Easy to customize content for your own Mother's Day wishes or project
- Responsive layout 
- Fast and lightweight

## Usage

1. **Clone or Download** this repository:
    ```bash
    git clone https://github.com/DigitalDreamer5/Mother-s-Day.git
    ```
2. **Open `index.html`** in your web browser.

## Customization

- Replace the existing HTML content with your own Mother's Day messages, photos, or styling.
- Update colors, fonts, or layout by editing the CSS within your HTML file.
